# Change record

Append one entry at the bottom for each requirement change, optimization, bug fix, or behavior-affecting maintenance change. Cite directly affected tests; a bug fix must cite an added or updated regression test. Non-bug changes may cite unchanged tests with `existing coverage: <scenario and why no test change is needed>`. Documentation-only changes may use `not applicable` with a short reason.
