# Source synthesis

This standard extracts reusable engineering lessons from three repositories while excluding their product-specific facts.

## PinChina contributions

- concise architecture lock and minimal-diff AI decision rules;
- API/schema-first work, shared SDK/types/UI packages, Better Auth as an approved project-specific choice;
- MySQL migration compatibility as a valid non-default branch;
- bilingual typed-copy rules, design-token authority, provenance and moderation gates;
- S3/R2 presigned upload lifecycle and overseas-first weak-network/accessibility concerns.

## ResonA contributions

- approved development baseline with explicit authority order and change control;
- conservative pinned stack, strict TypeScript, modular monolith, PostgreSQL Job worker;
- domain/application/infrastructure/presentation layering;
- strong API, migration, consent, cultural-source, AI-review, and release contracts;
- vertical-slice delivery before horizontal content expansion.

## ThreadInk contributions

- one canonical `AGENTS.md` with tool-specific pointer files;
- pnpm + Turborepo app/package boundaries and a stronger quality/security toolchain;
- NestJS + Fastify, transactional outbox + SQS, Redis as non-authoritative infrastructure;
- append-only money/score/audit facts, integer monetary rules, idempotency and rule snapshots;
- browser, cross-browser, accessibility, visual, SAST, SBOM, secrets, and supply-chain gates.
- canonical multi-agent adapters, requirement traceability, independent AI review, and non-blocking human participation.

## Synthesis policy

- Use the strongest shared safety and quality rule.
- Keep architecture additions conditional rather than making the default stack maximal.
- Keep product truth, business constants, content authority, and AI permissions outside the reusable template.
- Prefer one canonical rule source, explicit decision records, exact validation evidence, and a minimal modular monolith.
- Make AI review mandatory for pure-AI delivery while keeping human review optional unless external authority requires it.
